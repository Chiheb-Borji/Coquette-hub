# Coquette HUB

Internal operations and analytics platform developed to centralize
business workflows around an e-commerce activity.

## Features

### Dashboard
Central operational overview.

### CRM
Customer and contact management.

### Tasks
Task management with:

- Assignees
- Status
- Priority
- Dates
- Labels
- Attachments
- Comments
- Checklists

### Tickets
Internal support and incident management with:

- Departments
- Priority
- Assignee
- Service
- Tags
- Conversation history

### Team ToDo
Supervisor/Admin view of team ToDo activity.

### Marketing Workspace
Marketing planning including:

- Marketing plans
- Objectives
- Phases
- Daily actions
- Content categories
- Weekly/monthly calendar
- Marketing dashboard

### Statistics

Business analytics combining:

- PrestaShop orders
- Revenue
- Products
- Stock availability
- Stockouts
- Google Analytics sessions
- Page views
- Conversion indicators

### Roles & Permissions

Custom access control for:

- Administrator
- Super Administrator
- Standard User

### Multilingual

FR / EN interface using the native application language system.

## Architecture

Production architecture uses:

- PHP
- CodeIgniter
- MySQL
- JavaScript
- CSS
- PrestaShop
- Google Analytics 4
- Linux
- Proxmox
- LXC
- Nginx

## Repository Scope

This repository contains only custom development created for
the HUB.

The commercial Perfex CRM core is NOT included.

Production data, passwords, API keys, server configuration,
customer information and backups are NOT included.

## Database

`database/custom_schema.sql`

contains database structures only.

It contains no customer or production data.
